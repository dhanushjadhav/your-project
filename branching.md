# Team Branching Strategy

## Main Branch
The main branch contains stable and approved project code.

## Feature Branches
Each developer creates a separate feature branch.

- Developer 1: feature/login
- Developer 2: feature/dashboard
- Developer 3: feature/profile

## Workflow
1. Developers create feature branches from main.
2. Each developer works independently.
3. Changes are saved using meaningful commits.
4. Completed features are merged into main.
5. Merge conflicts are reviewed and resolved before merging.

## Commit Message Convention
Use clear messages such as:
- Add login functionality
- Update dashboard design
- Fix profile validation

## Rule
Developers should not directly modify main while developing new features.
